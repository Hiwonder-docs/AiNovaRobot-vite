3. Program Download ​

3.1 Program Download ​

NOTE

This lesson will demonstrate how to download program to AiNova. The game program has been placed in Appendix under the same directory. You can copy the programs to your computer in advance to facilitate the following operations.

3.1.1 Getting Ready ​

  • Software Installation

Please view WonderCode installation method in folder “1.Getting Ready/Lesson 3 Software Program” to install WonderCode and learn about the function of software interface.

  • Hardware Preparation

According to “Lesson 1 Mini AI Autonomous Driving Kit Introduction”, after assembling this kit, prepare AiNova (flat view), traffic light controller and USB cable, as the figure shown below:

3.1.2 Load Program ​

  1. Open WonderCode.
  1. Click “File”, and then click “Load file from your computer”, as the figure shown below:
  1. Then choose “Mini AI Autonomous Driving Program” and click “Open” to load game program in software interface or directly drag the program to software interface.

3.1.3 Program Download ​

  1. Connect AiNova robot to your computer with USB cable.

  2. Click “Connect device” in home interface and select corresponding port. (The port number is selected based on actual situation. The following example port is COM9. )

NOTE

If COM1 appears, please do not select. COM1 is a system communication port.

  1. After connecting, Click “Upload” in upload mode.
  1. Wait until the download is completed.
  1. Traffic light program is downloaded according to the same method. You just need to replace the program in “2.Load Program”

3.2 Program Logic Analysis ​

3.2.1 Lesson 1 Logical of Traffic Light Program ​

The screenshots used in this file are not the complete program. If want to view the detailed content , please go to this folder “Mini Autonomous Driving Kit/3.Program Download/Appendix”.

In this game, RGB module plays the role of traffic light. Let’s analyze how to set up a program to realize the cyclic and alternating flashing of red and green lights.

RGB module needs to keep flashing so the repeat executing statement will be used in here.

  1. Then drag the program block of RGB module color setting and set the port to 8, and two RGB lights are red.
  1. Then set the duration time of red light.
  1. After setting red, then green. Likewise, add a delay. The duration can be set according to the actual situation.
  1. At this step, the entire traffic light program has been programmed.

3.2.2 Lesson 2 Logical of Autonomous Driving Program ​

The screenshots used in this file are not the complete program. If want to view the detailed content, please go to this folder “Mini Autonomous Driving Kit/3.Program Download/Appendix”.

  1. Firstly, initialize each module.
  1. Then set whether to turn left or right after robot car recognizes the road sign. In order to make the program framework more intuitive and neat, the method of sub-threading is used here to program.

The specific program for detecting road sign is as follow:

  1. Switch WonderCam vision module to Landmark recognition.
  1. Next, the following several functions are used to control robot car to follow line.
  1. Updating line following sensor is mainly to update the detection values of the sensor’s four probes in real time, as the figure shown below:
  1. The function of the white line detection is to set the variable of white line detection to 1 if the white line is detected by four probes.
  1. The general line following logic program can make the car move forward and turn according to the detection situation of the four probes.
  1. When WonderCam recognizes ID2 or ID3, that is, turning left or right, the robot car will stop and end the road sign recognition.
  1. When WonderCam recognizes the road sign card of ID2, that is, turn left, set the robot car to turn left, otherwise, turn right.
  1. Then, the robot car keeps moving. When four probes detect the white line, the traffic light detection starts.
  1. After the robot car recognizes the green light, it will broadcast the audio that allows passage once, and the broadcast cannot affect the traffic light detection, so set green to 1 and use a loop statement to make WonderCam detect repeatedly.
  1. Finally, through repetition execution statement, the entire recognition process is repeated to realize the effect that the car recognizes and moves continuously.
